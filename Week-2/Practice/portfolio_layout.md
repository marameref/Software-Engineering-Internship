
# Session 2 Assignment
## Personal Portfolio — Layout Version

**Topic:** CSS Box Model, Flexbox, and Page Layout  
**Level:** Beginner  
**Project:** Personal Portfolio Website

---

## Assignment Overview

In this assignment, you will improve the personal portfolio website you created earlier.

Your goal is to make the website more organised, visually appealing, and easier to navigate using the HTML and CSS concepts covered in Session 2.

You are expected to apply what you have learned about:

- CSS Box Model
- Margin and padding
- Borders and border-radius
- Flexbox
- Element alignment
- Basic responsive design

## Assignment Requirements

### Task 1: Create a Horizontal Navigation

Improve the navigation menu in your portfolio.

Your navigation should:

- Display links horizontally.
- Include at least three links: Home, About, and Skills.
- Have appropriate spacing between links.
- Use Flexbox to arrange the navigation items.

### Task 2: Improve Section Spacing

Organise the sections of your portfolio.

- Add consistent spacing between sections.
- Use margins and padding appropriately.
- Ensure that text and images are not too close to one another.
- Make the content easy to read.

### Task 3: Use Flexbox in Two Areas

Apply Flexbox in at least two different areas of your website.

Examples include:

- Header and navigation
- Introduction and profile image
- Skills or interests cards

Use properties such as:

- `display: flex`
- `justify-content`
- `align-items`
- `gap`
- `flex-direction`

### Task 4: Create Three Skill or Interest Cards

Create at least three visually distinct cards.

Each card should contain:

- A skill or interest title.
- A short description.
- Appropriate padding.
- A border or background colour.
- Rounded corners using `border-radius`.

Arrange the cards using Flexbox.

### Task 5: Improve the Profile Image Layout

Improve how your profile image appears on the website.

Your image should:

- Have an appropriate width and height.
- Be positioned neatly beside or within the introduction.
- Have rounded corners or a circular appearance.
- Maintain its proportions without stretching.

### Task 6: Organise Your HTML and CSS

Keep your project files clean and readable.

- Use meaningful HTML elements.
- Use `<section>` for meaningful page sections.
- Use `<div>` when grouping elements for layout.
- Give elements appropriate class names.
- Keep CSS in a separate `style.css` file.
- Use comments where necessary.
- Maintain consistent indentation.
